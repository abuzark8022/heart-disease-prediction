## 📌 Project Overview
This project develops an end-to-end Machine Learning System to predict the presence of coronary heart disease based on structured clinical patient data from the **UCI Heart Disease (Cleveland) dataset**.

Following the instructor's **Half-Cooked Teaching Framework**, the system replicates the exact 4-phase, 10-step lifecycle of the benchmark Titanic Passenger Survival Prediction project while strictly satisfying the assignment constraints:
- **Constraint Compliance:** Exactly **4 input attributes** are selected from the 14 attributes in the UCI Heart Disease dataset.
- **Model Choice:** Support Vector Classifier (SVC with `gamma='auto'`) trained on reproducible 80/20 train/test splits.
- **Enhanced Evaluation:** Pre-training exploratory data visualizations, multi-model benchmark (SVC vs. Logistic Regression vs. Decision Tree), and comprehensive classification metrics (Precision, Recall, F1-Score, and Seaborn Confusion Matrix Heatmap).
- **Clinical Performance:** The trained SVC achieves **75.41% accuracy** with balanced diagnostic recall and precision across positive and negative test cases.

## 📂 Features Selected (Constraint: 4 Input Attributes)

| Attribute Name | Raw Attribute in UCI Dataset | Clinical Possible Values | Clinical Meaning |
| :--- | :--- | :--- | :--- |
| **AgeGroup** | #3 (`age`) | `Young`, `MiddleAged`, `Senior` | Young (<45 yrs), Middle-Aged (45–60 yrs), Senior (>60 yrs) |
| **Sex** | #4 (`sex`) | `Male`, `Female` | Biological sex |
| **ChestPain** | #9 (`cp`) | `TypicalAngina`, `AtypicalAngina`, `NonAnginal`, `Asymptomatic` | Clinical chest pain classification |
| **ExerciseAngina** | #38 (`exang`) | `Yes`, `No` | Angina pectoris provoked by exercise |
| **HeartDisease (Target)** | #58 (`num`) | `Yes`, `No` | Angiographic disease status (>50% narrowing) |
